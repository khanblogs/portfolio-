Azure → GCP re-platforming, finished early

Re-platforming

Smartvizx — DevOps Architect, Jul–Dec 2023 · migration-specific engagement

The brief: re-platform a production Azure estate onto Google Cloud — full parity — verified endpoint by endpoint before cutover.

What was done

  • Re-platformed the workloads onto GKE, pipelines rebuilt on Cloud Build, and keyless service auth via Workload Identity — endpoint parity verified service-by-service before cutover.
  • Introduced the Istio service mesh — mTLS, per-route retry/timeout policies, and deliberate traffic shaping — so latency behaviour became a policy, not an accident.
  • Left no key-management debt: no long-lived credentials, no snowflake environments.
