Umangverse — the immersive UMANG experience

Government · Web experience

NeGD (MeitY) · UMANG ecosystem — designed, built & set up end-to-end

The brief: design and build Umangverse — the immersive web experience in the UMANG ecosystem — and own its platform end-to-end: deployment, hardening and security assurance to the same standard as the core platform.

What was done

  • Built the experience end-to-end (Vite + TypeScript, served by nginx) and deployed it as a containerized service behind a reverse proxy with TLS on NeGD infrastructure — the application listens on loopback only; the proxy is the single public face.
  • Delivered a full SAST review of the codebase — a findings report with severity ratings and remediation guidance the team could act on directly.
  • Took the experience to its v2.0 release under the same release discipline as the core UMANG platform.
