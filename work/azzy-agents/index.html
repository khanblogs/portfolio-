Azzy Agents — a self-hosted AI agent platform

Flagship · AI platform

Sarvnex Technologies — independent build: designed, built, set up & operated end-to-end

The brief: build a personal AI agent platform that is genuinely model-agnostic — agents that keep working when any single model provider is down, rate-limited, or repriced — without handing the keys to a third-party AI SaaS.

What was done

  • Architected the platform on Docker Compose (EC2): agent API and workers sit behind an LLM gateway (OmniRoute) with provider abstraction and automatic failover across models — no single-vendor dependency anywhere in the chain.
  • Kept the intelligence local where it matters: a fully self-hosted embeddings pipeline for retrieval, with LLM traffic routed through a cost-optimised fallback chain — inference runs at near-zero marginal cost while staying swappable.
  • Operated like a production service, not a demo: TLS, health checks, backups, and a written audit of the platform's cost, reliability and certificate posture.

KEY DECISIONS & ALTERNATIVES
Provider-agnostic gateway, not direct SDKsAll inference routes through OmniRoute + freellmapi, so models are swappable parts with a cost-optimised failover chain — no vendor lock-in at the agent layer.
Local embeddings in PostgreSQL + pgvectorRetrieval stays self-hosted instead of an external vector SaaS — one less dependency, one less data egress.
Compose on one node, deliberatelyAt current scale a disciplined Docker Compose stack beats operating Kubernetes for a personal platform — the complexity budget is spent on the agents, not the substrate.
LIMITATIONS & LESSONS
LimitationsSingle-node deployment is not high-availability, and the cost strategy leans on free model tiers — a production client deployment would pin paid models behind the same gateway.
LessonFailover is a product feature: the day a free model degraded, the chain absorbed it and no agent task failed.
LessonMemory quality beats model size — curated local embeddings improved agent answers more than a bigger LLM did.
