Government production fleet — NFS, UPMS & beyond

Government · Operations

NeGD (MeitY) — production operations across programmes

The brief: beyond UMANG, run production for a fleet of government platforms — NFS (NITI Aayog) on GCP, UPMS on AWS, MoSPI staging estates and a 20-microservice hospital platform (HMS) — under one secure access and release model.

What was done

  • NFS production (NITI Aayog, GCP): bastion-mediated production access and staged deployments — release v3.94 verified live with a full smoke suite — under strict session-hygiene rules for production shells.
  • UPMS production (AWS): a dated-branch release workflow with pre-built images and rollback tags across backend, auth, admin and frontend services — deploys that can always be undone.
  • One secure mesh: built a Tailscale network across 19 servers spanning AWS, GCP and on-premise estates, so production access no longer depends on brittle public-IP allowlists — and run HMS, a 20-microservice hospital system with hospital-wide Voice AI, on the same operating discipline.
